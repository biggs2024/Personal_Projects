Title: Maze Solver

Core Idea: This program designs a randomized maze and solves it utilizing Depth-First Search and Breadth-First Search, then compares results

Why make it: General practice with basic Java concepts and further expansion and challenge of what I know.

End Goal:
The program should:
1. Generate a valid maze at user-selected dimensions
2. Solve the maze using DFS and BFS
3. Optionally include a JavaFX visual mode for step-by-step animation

Version 1 Scope: 
1. Console-based maze generator
2. Console rendering of maze using characters
3. DFS solver
4. BFS solver
5. Simple comparison metrics
   -  solved or not
   -  cells visited
   -  path length
   -  runtime in milliseconds
6. Fixed text-file save and load for maze data

Success criteriea: 
1. Program generates a random maze at least 3 different sizes
2. Both DFS and BFS can solve generated mazes reliably
3. Output clearly shows solved path
4. Comparison metrics print for both algorithms
5. Maze can be saved and loaded from a file without corruption

Tech used: 
- Java
- Standard file I/O
- Optional JavaFX in later versions
